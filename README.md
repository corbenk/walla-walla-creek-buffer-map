# Walla Walla creek buffer map
Static site: "Is your property in the proposed 100-foot stream buffer?" for the City of Walla Walla Critical Areas Ordinance update (public hearing Oct 14, 2026; adoption vote Oct 28, 2026).
No backend. Reads the City of Walla Walla's public GIS map service and Walla Walla County's parcel service live in the browser. Source project: `wa-critical-areas/map-app/` on Corben's machine. Deploy: Render static site via `render.yaml` (publish path `.`).
